# Functionally graded metal foam simulation

The aim of this program is to solve the continuity equation along with the equations for momentum (for the fluid phase) and energy conservation (for both the fluid and solid phases).

Consider the Navier-Stokes equation for an incompresible fluid:
$$ \rho_f \left[ \frac{\partial \vec{u} }{\partial t} + \nabla \cdot \left( \vec{u} \, \vec{u}  \right) \right] = \nabla p + \mu \, \nabla^2 \vec{u}$$

And evaluate the volumetric average over a representative elemental volume inside the domain describing a porous media.
